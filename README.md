# 🚌 Bus Reservation System

A simple console-based Bus Reservation System developed using Core Java, Object-Oriented Programming (OOP), and ArrayList collections.

## 📌 Features

- View available buses
- Check seat availability
- Book bus tickets
- Passenger information management
- Prevent overbooking
- Simple and user-friendly console interface

## 🛠️ Technologies Used

- Java
- OOP Concepts
- ArrayList
- VS Code

## 📂 Project Structure

Bus Reservation System
│
├── Bus.java
├── Booking.java
└── BusReservationSystem.java

## 🚀 How to Run

1. Clone the repository
2. Open the project in VS Code
3. Compile the files

```bash
javac *.java
```

4. Run the application

```bash
java BusReservationSystem
```
